📚On the Shelf

On the Shelf is a book rating and review application that allows users to discover books, rate their reads and keep track of their reviews in one place.

Users can create an account, log in securely, search for books using the Open Library API and submit personal ratings and reviews. Each user's ratings are saved to their account, allowing them to revisit their reading experiences whenever they log in.

Features:
User Registration: Create an account with a username, email and password.
User Authentication: Log in using existing account credentials.
Book Search: Search for books using the Open Library API.

Book Ratings: Rate books on a scale of 1–5.
Book Reviews: Write personal reviews.
Personal Account: View account information and previously submitted book ratings.

User Reviews: Each user can only retrieve their own ratings.
Logout: Log out and clear locally stored authentication information.
